# AI FAQ Chatbot

## About
An AI FAQ Chatbot built using Python as part of CodeAlpha AI Internship.

## Features
- Clean and attractive dark UI
- Answers questions related to Artificial Intelligence
- Uses NLP techniques for text matching
- Cosine Similarity for finding best matching answer
- Press Enter or click Send button to chat

## Technologies Used
- Python 3.10
- Tkinter (GUI)
- NLTK (Natural Language Processing)
- Scikit-learn (TF-IDF and Cosine Similarity)

## Topics Covered
- Artificial Intelligence
- Machine Learning
- Deep Learning
- Python
- NLP
- Neural Networks
- Data Science
- Computer Vision
- Reinforcement Learning
- Big Data

## How to Run
1. Install libraries:
   pip install nltk scikit-learn
2. Run:
   python chatbot.py
